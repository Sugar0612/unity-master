# unity-master —— Unity 高级工程师训练场

> 一份从"中级下沿"到"高级工程师"的成长档案：摸底 → 定制训练 → 项目实战 → 简历同步。
> 由 AI 教练 + 训练者共同维护，所有结论以代码和笔试证据为准，不搞感觉打分。

## 这个仓库是什么

- **训练场**：26 周 · 4 个 Phase 的定制训练计划，每周一个单元（概念精讲 + 手写实战 + 批改复盘）
- **成长档案**：摸底报告、批改记录、错题本、门禁验收——每一步可追溯
- **简历底气**：训练产出与简历声明逐条对照，"简历上每句话都顶得住三层追问"是最终标准

## 训练规则（详见计划文件）

1. 训练任务**禁 AI**、闭卷。工作中照常用 AI，但每段 AI 代码必须能逐行讲清
2. 门禁制：每 Phase 结束闭卷重考 + 实战验收，不过不放行
3. 实战素材优先用训练者自己的项目（CNCore / RSHE / SNNU / Essentials 框架）——修自己的 bug
