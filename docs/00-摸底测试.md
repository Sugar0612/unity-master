# 摸底测试

**目的**：确定你在 8 个维度上的真实水平，作为定制训练计划的依据。

**规则（重要）**：
- 闭卷。不查资料、不问 AI、不在 Unity 里跑代码验证——考的是你脑子里已经装了什么。
- 不会就写"不知道"。这比编一个错误答案强：瞎编按 0 分处理，且计入"虚假自信"记录（这项比无知更危险）。
- 允许画图、写伪代码。建议一口气做完，总时长 60~90 分钟。
- 答案写在 `docs/00-摸底答卷.md`（已建模板），或直接在对话里发给我，都可以。

**评分**：每题 0~3 分。
- 0 = 完全不知道
- 1 = 听过这个概念，但说不清细节
- 2 = 会用，原理模糊
- 3 = 原理清楚，且有实战经验

满分 60。级别映射：

| 得分 | 结论 | 训练路线 |
|------|------|----------|
| ≥48 | 接近高级 | 查缺补漏 + 高阶实战 + 架构深度 |
| 36~47 | 中级偏上 | 补原理深度 + 模块强化 |
| 24~35 | 中级 | 系统重建知识体系 + 密集训练 |
| <24 | 基础不牢 | 从核心机制重新打地基 |

## Part A · C# 语言与运行时

**A1 ★★** 下面每行分别会不会产生堆分配（GC Alloc）？是装箱还是普通分配？逐行说明：

```csharp
int score = 100;
object o = score;                 // ①
string s = "Score: " + score;     // ②
Debug.Log(s);                     // ③
string t = score.ToString();      // ④
```

**A2 ★★★** 这段代码给一个按钮挂了 3 个监听。点击一次按钮，控制台输出什么？为什么？给出两种修复方式：

```csharp
for (int i = 0; i < 3; i++)
    button.onClick.AddListener(() => Debug.Log(i));
```

**A3 ★★★** 协程不是线程。那它到底靠什么实现"暂停/恢复"？请从 `IEnumerator` 和引擎每帧做的事讲起。另外回答：
- 把 MonoBehaviour 的 `enabled` 设为 false，协程停吗？把 GameObject `SetActive(false)` 呢？
- `async/await` 在 Unity 里默认在哪个线程上恢复执行？和协程相比，你各会在什么场景选谁？

**A4 ★★** `Destroy(go)` 之后**下一行**立刻 `if (go == null)`，结果是 true 还是 false？为什么"对象明明还没被 GC 却等于 null"？`Destroy` 和 `DestroyImmediate` 的关键区别？`go?.name` 和 `if (go != null) go.name` 行为有差异吗？

## Part B · Unity 核心机制

**B1 ★★** 把以下回调按**一帧内的真实执行顺序**排列：
`Awake / OnEnable / Start / Update / LateUpdate / FixedUpdate / 协程 yield null 的恢复点 / OnDestroy`
并回答：FixedUpdate 在一帧内可能执行 0 次吗？可能执行 2 次吗？由什么决定？

**B2 ★★** 相机跟随代码 `cam.transform.position = target.position;` 写在 Update 里有时抖动，挪到 LateUpdate 就好了。为什么？LateUpdate 又**解决不了**哪类抖动（举一例即可）？

**B3 ★★** 大量子弹用 Instantiate/Destroy 反复创建销毁会卡。除了"用对象池"这个结论，请解释 **Instantiate 到底贵在哪**——至少说出 3 个底层层面的原因。

**B4 ★★★（网络）** `[SyncVar]` 到底是怎么"生效"的？写出它的实现原理（提示：编译后发生了什么）。据此回答：
- 给 `public static int count` 加上 `[SyncVar]`，它能同步吗？为什么？
- 在**客户端**脚本里直接给一个 SyncVar 字段赋值，会发生什么？

**B5 ★★★（网络）** 客户端按钮 onClick 里调用一个 `[Command]`，服务器处理后通过 `Rpc` 修改了某个 SyncVar。onClick 的**同步代码里、Command 调用的下一行**就去读这个 SyncVar，能读到新值吗？为什么？正确的写法应该是什么样的？
