# 定制训练计划（Phase 0.3 产出，2026-10-13）

## 定级结论

**当前：中级下沿。目标：26 周达到高级工程师水位。**

核心矛盾一句话：**架构直觉和交付能力 ≥ 中级，运行时原理深度 ≈ 初级**（笔试 24/66）。所有模块围绕消除这个落差设计，实战素材优先用你自己的项目（CNCore/RSHE/SNNU/Essentials）——修自己的 bug 比做练习题有效十倍。

## 训练规则（先读三遍）

1. **训练任务禁 AI**。所有训练代码手写、所有测验闭卷。工作中照常用 AI——但每次接受 AI 生成的代码前，必须能逐行讲清它为什么这样写，训练中我会抽查。
2. **训练循环**：出题 → 闭卷作答 → 逐题批改讲透 → 错题入错题本 → 阶段末闭卷重考。**错题不消灭不出阶段**（门禁制）。
3. **节奏**：每周 1 单元（5~10h：精讲自学 1-2h + 手写实战 3-5h + 批改复盘 0.5-1h）。允许攒假，但一个 Phase 不超过 2 周停训。
4. **产出归档**：训练答题/代码放本仓库 `modules/phase<N>/`；修自己项目的 bug 在原仓库做，把 diff 说明贴回本仓库。
5. **诚实条例**：不会写"不知道"，不许查。摸底已证明你有这个品质，保持住。

## 门禁标准

- **M1**：A/B 重考 ≥80% + 6 个真 bug 修复通过验收 + 迷你协程驱动器能跑
- **M2**：性能审计报告有修复前后真机数据 + WebGL 包浏览器跑通
- **M3**：8 个 shader 闭卷手写通过 + 逐行讲解无卡壳
- **M4**：毕业项目完成 + 答辩通过（标准：任意一层我能问倒你的问题 ≤2 个）

## 错题本机制

`docs/错题本.md`：每道错题记 [题目 / 你的错误模型 / 正确模型 / 错因分类（概念缺失/模型错误/规则记忆/手滑）]。每个 Phase 结束闭卷重考本阶段错题，全对才放行。

## 与 AI 的关系（回应你 Part 0 的担忧）

你的判断完全正确：全靠 AI 写代码，理解和不可替代性都会流失。本计划的立场——
- **训练场内**：禁 AI。手写是唯一能重建心智模型的方式。
- **工作场内**：继续用 AI 提效，但执行"逐行讲清"纪律。六个月后你要达到的境界是：**AI 写得对不对、好不好，你一眼能判断；AI 写不了的你亲手写**。这是"高级工程师"在 AI 时代的定义。
